# Medidor Arduino original

Sketch de Arduino para el sensor HELLA 6PP 010 378-101 y pantalla OLED monocroma de 128×64.

## Archivos

- `Oil_temp_pres_en.ino`: sketch Arduino.
- `images/vista-oled-original.png`: reconstrucción visual ampliada del diseño del sketch, con valores de ejemplo. No es una foto de una unidad física.

El montaje y el cableado aparecen en el [video del autor](https://youtu.be/Wn5kIrU5_tc?t=408). La alimentación desde el encendido se explica alrededor de 4:22 y la caja con el Arduino Nano y el cableado alrededor de 6:48.
